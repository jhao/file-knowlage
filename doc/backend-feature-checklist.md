# 后台系统待完善功能清单（基于当前前端功能反推）

> 目标：将现有前端可见能力落地为可生产运行的服务端后台系统。

## P0：必须优先完成（无后台无法闭环）

## 1) 认证与权限中心
- [ ] 登录/鉴权（JWT 或 Session）
- [ ] 用户、角色、权限模型（管理员/普通用户 + 能力位）
- [ ] 接口级鉴权中间件（查看、上传、导出、修改、删除、审批）
- [ ] 数据权限（按部门、密级、上传者隔离）
- [ ] 操作审计日志（登录、审批、修改、删除、导出）

## 2) 档案主数据服务
- [ ] 档案 CRUD（文档基础信息、状态、归属、路径）
- [ ] 元数据管理（标题、分类、关键词、摘要、密级、置信度等）
- [ ] 知识实体管理（实体类型、上下文定位、置信度）
- [ ] 状态机流转（上传/处理中/待审核/已归档/驳回/待审批）
- [ ] 历史版本与变更记录（便于追溯）

## 3) 文件上传与存储
- [ ] 单文件、批量文件、文件夹上传接口
- [ ] 对象存储集成（MinIO/S3/OSS）
- [ ] 分片上传与断点续传（大文件）
- [ ] 文件指纹与去重策略
- [ ] 上传安全校验（类型白名单、大小限制、恶意文件扫描）

## 4) AI 任务编排与解析流水线
- [ ] 异步任务系统（队列 + Worker）
- [ ] 文档解析（OCR、版面、文本抽取）
- [ ] 音视频解析（ASR 转写、时间戳）
- [ ] LLM 结构化提取（分类、摘要、实体）
- [ ] 失败重试、超时控制、幂等处理
- [ ] 任务状态回写并通知前端刷新

## 5) 校验与审批后台
- [ ] 待审核队列接口（分页、筛选、排序）
- [ ] 审核通过/驳回接口（记录审核意见）
- [ ] 高风险操作审批流（删除、导出、密级调整）
- [ ] 审批节点配置（单级/多级）

---

## P1：强烈建议尽快补齐（提升可用性）

## 6) 检索与查询服务
- [ ] 归档列表查询（状态、类别、部门、时间、上传者）
- [ ] 全文检索（标题/摘要/正文）
- [ ] 实体检索（人名/机构/事件）
- [ ] 组合筛选与保存查询条件

## 7) 统计分析服务（对接仪表盘）
- [ ] 总量、待校验、处理中、已归档指标接口
- [ ] 月度趋势统计接口
- [ ] 分类占比统计接口
- [ ] 指标缓存与定时预计算

## 8) 用户与系统配置后台
- [ ] 用户管理 API（增删改查）
- [ ] 角色权限模板管理
- [ ] 系统参数配置（实体类型、分类映射、敏感词策略）
- [ ] 配置变更审计与回滚

## 9) 通知与消息中心
- [ ] 任务完成通知（站内信/WebSocket）
- [ ] 审批待办提醒
- [ ] 异常告警（任务失败率、积压阈值）

---

## P2：中长期优化（规模化与治理）

## 10) 合规与安全增强
- [ ] 数据脱敏与水印策略落地
- [ ] 下载/导出授权校验
- [ ] 密级升降审批与复核
- [ ] 数据生命周期（归档、冻结、销毁）

## 11) 稳定性与运维
- [ ] 链路追踪与统一日志
- [ ] 健康检查与熔断限流
- [ ] 灰度发布与回滚方案
- [ ] 自动化备份与容灾恢复

## 12) 开放能力
- [ ] 对外 OpenAPI（上传、查询、回调）
- [ ] Webhook 事件订阅（任务完成、审批状态变化）
- [ ] 与学校统一身份、OA、数据中台集成

---

## 建议的数据表（最小可用集合）
- [ ] `users` / `roles` / `permissions` / `user_role_rel`
- [ ] `archives`（主档案）
- [ ] `archive_metadata`（结构化元数据）
- [ ] `archive_entities`（知识实体）
- [ ] `archive_versions`（版本历史）
- [ ] `upload_tasks` / `ai_tasks`（异步任务）
- [ ] `approval_records`（审批记录）
- [ ] `operation_logs`（审计日志）
- [ ] `system_configs`（系统配置）

## 建议的接口分组（REST 示例）
- [ ] `/api/auth/*` 认证鉴权
- [ ] `/api/users/*` 用户与权限
- [ ] `/api/archives/*` 档案与元数据
- [ ] `/api/uploads/*` 上传与文件管理
- [ ] `/api/tasks/*` AI 任务状态
- [ ] `/api/reviews/*` 审核与审批
- [ ] `/api/search/*` 检索查询
- [ ] `/api/stats/*` 仪表盘统计
- [ ] `/api/settings/*` 系统配置
